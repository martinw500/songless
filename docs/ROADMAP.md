# Roadmap

## Milestone 1 — playable local game

- [x] Responsive dark game interface
- [x] Five difficulty pools
- [x] Progressive intro stages
- [x] Precise local audio playback
- [x] Search and canonical song guesses
- [x] Skip, wrong-answer, win, and reveal states
- [x] No-repeat selection within a pool
- [x] Compact audio preparation script
- [x] Demo catalogue with generated audio

## Milestone 2 — real catalogue workflow

- [ ] Replace demo entries with the first 50 real tracks
- [ ] Add optional album artwork
- [ ] Add a catalogue validation command with useful line-level errors
- [ ] Add an in-browser curator screen
- [ ] Detect missing audio and artwork before starting a round
- [ ] Support multiple themed catalogues

## Milestone 3 — two-player quality

- [ ] Persist wins, misses, and solve stage locally
- [ ] Separate player profiles without requiring accounts
- [ ] Calibrate difficulty from both players' results
- [ ] Add session score and best-of-N rounds
- [ ] Add pass-and-play and shared-screen modes

## Milestone 4 — polish

- [ ] Keyboard shortcuts
- [ ] Answer-reveal animation and artwork treatment
- [ ] Optional 0.01-second joke stage
- [ ] Round history and replay
- [ ] Import/export private catalogue metadata
- [ ] Package as a local desktop application if desired
